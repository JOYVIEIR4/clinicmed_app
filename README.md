# ClinicMed App 

Sistema de gerenciamento hospitalar desenvolvido para auxiliar profissionais da saúde no controle de pacientes, médicos e medicamentos hospitalares.

A aplicação foi projetada para utilização por médicos, enfermeiros, técnicos de enfermagem e farmacêuticos, com foco em organização de informações e operações internas.

## Tecnologias utilizadas

* Python
* Flask
* MySQL
* HTML
* CSS
* Git/GitHub

##  Funcionalidades

* Cadastro de pacientes
* Cadastro de médicos
* Controle de medicamentos hospitalares
* Operações CRUD
* Integração com banco de dados MySQL
* Estruturação de API REST

## Objetivo do projeto

Projeto desenvolvido para prática de desenvolvimento Back-End, integração com banco de dados e simulação de um sistema aplicado a um ambiente hospitalar real.

## Conceitos praticados

* APIs REST
* CRUD
* Organização de rotas
* Estruturação Back-End
* Modelagem de dados
* Integração com banco de dados relacionais
* Boas práticas de programação
